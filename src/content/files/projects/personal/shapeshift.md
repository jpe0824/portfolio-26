# shapeshift

A workout app, and my university capstone.

React Native front end, Python backend. Plan workouts, log lifts, track
progress.

Four of us, with different priorities, different schedules, and different
definitions of "done." Getting people to converge on one thing turned out to
be harder than anything in the backlog, and it's the part I actually learned
from.

Not live. Private repo.

**stack**: React Native, TypeScript, Python, Docker
