# portfolios

One rebuild a year, from scratch, since 2023.

- 2023: `portfolio`, plain HTML
- 2024: `portfolio_24`, TypeScript
- 2025: `pf_25`, TypeScript, ambitions of self-hosting on a Raspberry Pi
- 2026: `portfolio-26`, this site

Each one is an excuse to use something new. Latest framework, a design
direction I haven't tried, something with no ticket attached. Professionally
a lot of my time goes to legacy systems and enterprise constraints. This is
the counterweight.

I usually get a v1 up and move on from the bigger ambitions. That's fine.
The point was never the finished site, it was the year of using the tools.
