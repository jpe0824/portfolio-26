# 1kout

A tracker for the 1000 Hours Outside challenge, built for my wife.

She wanted to log time outdoors against a thousand-hour goal for the year.
Nothing off the shelf fit, so I built one.

Idea to real deployment in a week. This was back when AI was still just a
chatbot, so every line was hand-written. React and TypeScript on the front,
FastAPI and MongoDB behind it, JWT auth with refresh tokens, containerized
with Docker.

**stack**: TypeScript, React, FastAPI, MongoDB, Docker

**source**: [github.com/jpe0824/1kout](https://github.com/jpe0824/1kout)
